# Safety-first GPS — final news-led prototype

Deploy every file in this directory to the GitHub Pages repository root. `index.html` is the landing page.

Navigation: Home → Routes → Safety News (`news.html`) → Community (`community.html`). `safety-data.html` remains a legacy informational page, not a bottom navigation destination.

**Data integrity:** `news-data.js` contains illustrative, unverified sample news descriptions inherited from the supplied prototype. They are NOT verified CNA/SPF/Straits Times articles. Their dates, sources and alleged incidents must not be treated as factual. Route safety is not established by these fixtures; all route times, distances and maps are schematic. Community comments remain exclusively in `community.html` and `reviews-data.js`, not in the route safety recommendation.

Safety News contains Wikimedia Commons location-reference photos with linked attribution; these are historical streetscapes, NOT incident scene photos. External photos require network access.

No live routing, news connector, official dataset, or real review database is configured. SOS is a confirmation-only preview.


## Official street lighting information
The safety-data.html page now links to three verified data.gov.sg government datasets: LTA Number of Street Lighting (2004-2017), LTA Lamp Post (Oct 2025), and SLA Lamp Post (Aug 2025). These are static source references, not live API data, and are not used for route safety scoring.
